# Share It - микросервисное приложение для аренды вещей
**Стек: Java, Spring Boot, Spring Data JPA, PostgreSQL, H2, Docker, DTO, Lombok, JUnit, Mockito, REST API**

## О проекте
Приложение для размещения объявлений для аренды вещей с возможностью взять вещь в аренду

Приложение содержит два микросервиса:
- server для бизнес-логики
- gateway клиент с валидацией

Микросервисы и база данных запускаются в собственных Docker контейнерах (3 шт.).

## Основная функциональность:
- создание, обновление и удаление пользователя
- создание, обновление вещей
- поиск вещей по имени или описанию
- создание и просмотр комментариев к вещам
- создание, просмотр и подтверждение бронирования
- создание запроса на необходимую вещь по описанию с дальнейшей возможностью создания вещи к запросу


## Эндпоинты

### Users
- **POST** /users - *добавить нового пользователя*

- **GET** /users/{userId} - *получение пользователя по id*

- **PATH** /users/{userId} - *обновление пользователя*

- **DELETE** /users/{userId} - *удаление пользователя*

### Items

- **GET** /items - *получить список вещей пользователя по id пользователя из заголовка*

- **GET** /items/{itemId} - *просмотр вещи по id*

- **POST** /items - *создание вещи пользователя*

- **PATH** /items/{itemId} - *обновление вещи пользователя*

- **GET** /items/{itemId}/search - *поиск вещи по имени или описанию*

- **GET** /items/{itemId}/comments - *создание комментария*

### Bookings

- **POST** /bookings - *создание бронирования*

- **PATH** /bookings/{bookingId}/ - *подтверждение или отклонение бронирования*

- **GET** /bookings/{bookingId} - *проверка подтверждения бронирования*

- **GET** /bookings/ - *получить список бронирований пользователя*

- **GET** /bookings/owner - *получить список бронирований вещей пользователя*

### Requests

- **POST** /requests/ - *создать запрос*

- **GET** /requests/ - *получить список запросов пользователя*

- **GET** /requests/all - *получить все запросы других пользователей*

- **GET** /requests/{requestsId} - *получить запрос по id*
